# Contributing

Keep the default hosted connection easy to use. Optional sources must use documented public read-only endpoints, retain attribution and restrictions, bound requests, and include mocked contract tests. Avoid background polling, paid calls and automatic third-party installation.

Use a virtual environment, install the package, and run `python -m unittest discover -s tests -v`. Do not add personal examples, credentials, resumes, inbox messages or production data. For bugs, share a minimal public-source example and sanitized error only. Opening a pull request is welcome; it does not publish or deploy a service.
